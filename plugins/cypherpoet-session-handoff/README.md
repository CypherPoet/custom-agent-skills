# cypherpoet-session-handoff

Write a structured handoff document so a fresh agent can resume long-running work without losing context.

## Installation

Install via the [`cypherpoet-toolchest`](https://github.com/CypherPoet/cypherpoet-toolchest) marketplace:

```shell
# Skip if you've already added this marketplace
/plugin marketplace add CypherPoet/cypherpoet-toolchest

# Install this plugin
/plugin install cypherpoet-session-handoff@cypherpoet-toolchest
```
