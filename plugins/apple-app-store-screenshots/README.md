# apple-app-store-screenshots

Apple App Store screenshot and app preview specifications.

## Installation

Install via the [`cypherpoet-toolchest`](https://github.com/CypherPoet/cypherpoet-toolchest) marketplace:

```shell
# Skip if you've already added this marketplace
/plugin marketplace add CypherPoet/cypherpoet-toolchest

# Install this plugin
/plugin install apple-app-store-screenshots@cypherpoet-toolchest
```

## Skills

| Skill | Description | Model-Invocable |
|---|---|---|
| [apple-app-store-screenshots](skills/apple-app-store-screenshots/SKILL.md) | App Store screenshot + app preview specs — exact dimensions per device class, the upload-the-largest / auto-scale model, format and count rules, capture & `fastlane` automation, and screenshot design for conversion. | Yes |
```
