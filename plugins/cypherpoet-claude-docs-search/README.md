# cypherpoet-claude-docs-search

Look up answers about Claude Code features and behavior in the official Claude Code documentation.

## Installation

Install via the [`cypherpoet-toolchest`](https://github.com/CypherPoet/cypherpoet-toolchest) marketplace:

```shell
# Skip if you've already added this marketplace
/plugin marketplace add CypherPoet/cypherpoet-toolchest

# Install this plugin
/plugin install cypherpoet-claude-docs-search@cypherpoet-toolchest
```
