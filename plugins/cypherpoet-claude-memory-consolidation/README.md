# cypherpoet-claude-memory-consolidation

Audit and consolidate Claude's per-project auto-memory directory, deduping, repairing, and pruning with per-cluster approval.

## Installation

Install via the [`cypherpoet-toolchest`](https://github.com/CypherPoet/cypherpoet-toolchest) marketplace:

```shell
# Skip if you've already added this marketplace
/plugin marketplace add CypherPoet/cypherpoet-toolchest

# Install this plugin
/plugin install cypherpoet-claude-memory-consolidation@cypherpoet-toolchest
```
