# cypherpoet-session-harvest

Run a pre-exit sweep of a conversation for learnings worth preserving in project memory.

## Installation

Install via the [`cypherpoet-toolchest`](https://github.com/CypherPoet/cypherpoet-toolchest) marketplace:

```shell
# Skip if you've already added this marketplace
/plugin marketplace add CypherPoet/cypherpoet-toolchest

# Install this plugin
/plugin install cypherpoet-session-harvest@cypherpoet-toolchest
```
