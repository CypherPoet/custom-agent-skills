# cypherpoet-react-three-fiber-kit

React Three Fiber (R3F) + drei tooling for declarative Three.js in React.

## Installation

Install via the [`cypherpoet-toolchest`](https://github.com/CypherPoet/cypherpoet-toolchest) marketplace:

```shell
# Skip if you've already added this marketplace
/plugin marketplace add CypherPoet/cypherpoet-toolchest

# Install this plugin
/plugin install cypherpoet-react-three-fiber-kit@cypherpoet-toolchest
```

## Dependencies

Installed automatically with this plugin:

| Plugin | Version | Description |
|---|---|---|
| [cypherpoet-threejs-kit](../cypherpoet-threejs-kit) | `latest` | Three.js / WebGPU / WebGL tooling. |
