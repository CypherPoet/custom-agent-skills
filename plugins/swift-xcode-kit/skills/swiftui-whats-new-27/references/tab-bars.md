# Prominent Tabs

Set `TabRole.prominent` on the tab that should occupy a separate, trailing position in the tab bar.

Apple's SwiftUI updates page names `TabRole.prominent` and its placement behavior, but it does not
state availability or show the initializer there. Before emitting code, open the symbol
documentation in the target Xcode SDK and follow the declared initializer and availability.

**Source:** <https://developer.apple.com/documentation/updates/swiftui>
