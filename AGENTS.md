# Workspace Rules

- This project is for storing custom skills.
- When asked to create a new skill, create it locally within this project's `skills/` directory (e.g. `skills/[skill-name]/SKILL.md`), rather than globally, unless otherwise specified.
- Use `/writing-skills` when creating or editing skills
- When a new skill is added to `skills/`, add a corresponding entry to `docs/README.md` index and create a `docs/<skill-name>.md` documentation page covering purpose, usage, examples, configuration, and changelog
