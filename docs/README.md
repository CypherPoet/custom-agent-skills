This directory contains detailed documentation for each skill in the collection.

## 📝 Documentation Guidelines

Each skill should have a corresponding documentation page that covers:

- **Purpose** — What the skill does and when to use it
- **Usage** — How to invoke and configure the skill
- **Examples** — Real-world usage patterns
- **Configuration** — Any required setup or environment variables
- **Changelog** — Notable changes and version history
